# E-Commerce-Website
A modern, responsive e-commerce website template featuring product listings, shopping cart functionality, coupon section, product detail pages, and a clean minimal UI. Designed with HTML, CSS, Bootstrap, and JavaScript, this template is fully responsive and optimized for real-world online shopping experiences.

---

## 🚀 Features

### 🛍️ Product Pages
- Dynamic product cards with images, pricing, and ratings  
- Dedicated product detail page with thumbnails and main image switching  
- Organized categories and clean grid layout  

### 🛒 Shopping Cart
- Add/Remove items from cart  
- Quantity update support  
- Auto-updating subtotal and total sections  
- Horizontal scroll responsiveness for small devices  
- Styled custom scrollbar for improved UX  

### 💰 Coupon & Checkout
- Coupon input UI  
- Cart totals summary box  
- Custom checkout button  
- Mobile-responsive layout  

### 📱 Fully Responsive UI
- Desktop header + mobile hamburger menu  
- Optimized grid for all breakpoints  
- Flexible layout using Bootstrap’s grid system  

### 🎨 Clean & Modern UI
- Minimal design language  
- Consistent spacing, colors, and typography  
- Hover effects, active nav indicator, styled scrollbars
